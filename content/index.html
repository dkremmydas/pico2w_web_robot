Robot Control Panel

Motor settings Default 15 (1-100). Steps from the start speed to full power, one every 0.3 s while a button is held. More steps = slower, smoother acceleration. Default 300 (0-1000). Power at the first step. Too low and wheels stop and buzz once the kick ends. Default 800 (0-1000). Start power for turning in place, which needs much more force. Default 100 (0-1000, 0 = off). How long a wheel gets the kick power when it starts, to break it free. Default 1000 (0-1000). Lower it for a gentler start; raise it if a wheel starts late or buzzes.
